# 🚀 Камroid M - Быстрый Старт

## ⚡ За 1 команду (Linux/macOS)

```bash
bash setup.sh
```

Установит:
- ✅ Node.js (если нет)
- ✅ Go (если нет)
- ✅ Git, build tools
- ✅ Все npm зависимости (Vite, React, TypeScript и т.д.)

---

## 📦 После setup - Сборка

### Dev режим (быстро, с горячей перезагрузкой)
```bash
npm run dev
# Откройте http://localhost:5173
```

### Production (Express сервер)
```bash
./build.sh
npm run start
```

### Production (Go сервер - рекомендуется)
```bash
./build.sh --go
cd dist && ./server
```

### Production (Go + полная обфускация)
```bash
./build.sh --go --clean --obfuscate
cd dist && ./server
```

---

## 📂 Результаты сборки

```
dist/
├── public/          ← Фронтенд (все статические файлы)
├── server           ← Go бинарник (или index.cjs для Node.js)
└── run.sh          ← Скрипт запуска
```

---

## 🔧 Полезные команды

| Команда | Что делает |
|---------|-----------|
| `bash setup.sh` | Первичная настройка окружения |
| `npm run dev` | Разработка с горячей перезагрузкой |
| `./build.sh` | Сборка для Node.js |
| `./build.sh --go` | Сборка для Go (продакшн) |
| `npm run build` | Только Vite сборка фронтенда |
| `npm run build -- --debug` | Отладочная сборка |

## 🌍 Развертывание

### Netlify (easiest)
```bash
git push  # Автоматический деплой
```

### Self-hosted с Caddy
```bash
./build.sh --go
caddy run --config Caddyfile
```

### Self-hosted с Nginx
```bash
./build.sh --go
# Скопировать nginx.conf в /etc/nginx/
sudo systemctl restart nginx
```

## ⚠️ Проблемы?

### `bash: sudo: command not found`
Вы на macOS. Скрипт автоматически переключится на Homebrew.

### `npm: command not found`
Запустите `bash setup.sh` еще раз для переустановки Node.js.

### `Permission denied`
```bash
chmod +x setup.sh build.sh
```

### Нужна полная документация?
Смотрите `INSTALL.md` (90+ строк с подробностями).

## 📋 Функции приложения

✅ **Динамический PWA манифест** - меняется при выборе режима приватности
✅ **Полная обфускация кода** - в продакшене
✅ **Аноним имена файлов** - только хеши ([hash].js)
✅ **Шифрование localStorage** - XOR + Base64
✅ **Service Worker** - работа без интернета
✅ **Безопасные заголовки** - CSP, HSTS и т.д.
✅ **Сжатие Gzip** - автоматическое
✅ **Умное кеширование** - манифест без кеша, остальное на год
